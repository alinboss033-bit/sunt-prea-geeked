# Sunt prea geeked

Trei plugin-uri VST3 pentru FL Studio: **Voce**, **Reverb**, **Delay**.
Fiecare are butoane rotative, module cu on/off și preseturi (în meniul de preseturi al plugin-ului).

## Cum le compilezi pe GitHub (fără să instalezi nimic)
1. Creează un repo nou pe GitHub și urcă tot conținutul acestui folder, inclusiv `.github/workflows/build.yml`.
2. Intră la tab-ul **Actions** → **Build VST3** → **Run workflow**.
3. După câteva minute, deschide rularea și descarcă **Sunt-prea-geeked-VST3** de la Artifacts.
4. Copiază folderele `.vst3` în `C:\Program Files\Common Files\VST3`.
5. În FL Studio: Options → Manage plugins → Find installed plugins.
